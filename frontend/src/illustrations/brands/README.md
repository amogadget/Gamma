# App marks

These local SVGs identify import/export formats. They are rendered as monochrome
CSS masks at the same size as the shared document icons, with no runtime downloads.

- Obsidian, Logseq and Zotero: [Simple Icons SVG assets](https://github.com/simple-icons/simple-icons/tree/develop/icons), retrieved 2026-09-15. The asset license is included in `LICENSE.md` (CC0). Brand names and marks belong to their respective owners.
- Gamma: geometry from `frontend/public/media/icons/favicon.svg`, with its background plate removed. Keep the mark in sync with that source.

Brand references: [Obsidian](https://obsidian.md/brand), [Zotero](https://www.zotero.org/support/brand), [Logseq](https://github.com/logseq/logseq).

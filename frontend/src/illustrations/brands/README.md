# App marks

These local assets identify import/export formats. SVGs render as monochrome CSS
masks; the Zotero app icon uses grayscale. All match the shared document icon size,
with no runtime downloads.

- Obsidian and Logseq: [Simple Icons SVG assets](https://github.com/simple-icons/simple-icons/tree/develop/icons), retrieved 2026-09-15. The asset license is included in `LICENSE.md` (CC0). Brand names and marks belong to their respective owners.
- Zotero: [official 256px app icon](https://www.zotero.org/support/_media/logo/zotero_256x256x32.png) from the [Zotero brand assets](https://www.zotero.org/support/brand). The original PNG is preserved; grayscale is applied only by CSS.
- Gamma: geometry from `frontend/public/media/icons/favicon.svg`, with its background plate removed. Keep the mark in sync with that source.
- Notion: [Simple Icons SVG asset](https://github.com/simple-icons/simple-icons/blob/develop/icons/notion.svg), retrieved 2026-09-16 (CC0). Used in the README connections illustration; the Zotero PNG is embedded there so the SVG has no external image dependencies.

Brand references: [Obsidian](https://obsidian.md/brand), [Zotero](https://www.zotero.org/support/brand), [Logseq](https://github.com/logseq/logseq).

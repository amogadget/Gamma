# Gamma 0.3.0 — handwriting blocks across Web and Desktop

This coordinated release ships the Web/server image, Gamma Desktop 0.1.6 and Gamma Connector 0.1.1 from the same source commit. The native iPad application is **not** included in this release or its source tree.

## What's new

- Web and Desktop render existing handwriting blocks directly on PDF pages, using page-relative bounds with crop-offset, rotation and zoom support.
- Notes show handwriting previews alongside their text and child blocks. Empty annotation text no longer causes Backspace to delete a handwriting block accidentally.
- The backend supports private, account-scoped, content-addressed drawing/PNG assets and idempotent ink and nested-note updates with revision-conflict checks.
- Drawing assets are preserved by full/scoped Gamma backup, import and readable exports; cleanup allows a staging grace period for interrupted uploads.
- Browser tests cover actual pdf.js overlay placement, rotated crop boxes, page isolation and zoom. The web test fixture is standalone and requires no iPad source files.

- [Gamma Desktop 0.1.6](https://github.com/amogadget/Gamma/releases/tag/desktop-v0.1.6): macOS Apple Silicon, Windows x86-64, Linux x86-64/arm64.
- [Gamma Connector 0.1.1](https://github.com/amogadget/Gamma/releases/tag/extension-v0.1.1): browser-extension ZIP, released alongside this update. Connector functionality is unchanged; its version is advanced for this coordinated release.

Desktop and extension downloads appear after their respective build workflows finish successfully. Publishing a GitHub extension ZIP does not itself submit an update to the Chrome Web Store.

## Upgrade and limits

Update the server/container and refresh existing browser tabs to load the new frontend. Existing blocks, PDFs and assets remain in the same data volume; no schema migration is required. Keep a normal data backup before upgrading.

Handwriting is displayed as a preview on Web/Desktop, not edited there. This release does not add automatic realtime cross-client refresh, audio/replay, or flatten handwriting into exported PDF/Zotero documents. Native asset access requires the owning account; shared-link viewers do not gain access to private drawing assets.

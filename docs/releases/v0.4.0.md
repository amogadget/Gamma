# Gamma 0.4.0 — handwriting, recording and synchronized Note Replay

This coordinated release ships Web/backend 0.4.0, Desktop 0.1.7 and Connector 0.1.2 from the same source commit. It also includes the native iPad client source, tests and self-signing deployment guide. No personal-team iPad binary or signing credentials are distributed.

## What's new

- **Browser Note Replay:** play/pause recorded AAC audio, seek across segments and PDF pages, progressively reveal final surviving handwriting, and click timed ink to jump back to its audio position.
- **High-resolution static handwriting:** PDF overlays and Notes thumbnails reuse the same native-exported stroke images as Replay. Valid preview data no longer drops back to a lower-resolution whole-block PNG when playback ends.
- **Handwriting note navigation:** a distinct pen marker identifies handwriting blocks; clicking the marker/card/preview jumps to the annotation's position and briefly outlines it, with crop/rotation/zoom and horizontal-scroll handling.
- **Native iPad Gamma client:** same-account library/block identity, grouped PencilKit annotations, durable outbox, native text selection/highlight creation, segmented recording, recovery and native Replay.
- **Full Gamma Web workspace inside iPad:** reuse the Markdown/math editor, block tree, search, AI, settings and transfer UI, with a validated same-account handoff to/from native Pencil & Audio.
- **Safe cross-platform preview assets:** private, source-hash-bound `.inkjson` assets carry final per-stroke PNGs and numeric reveal paths. Existing ink can be backfilled without changing its source bytes, comment or ink revision.
- **Native-manifest protection:** Web text/tree saves preserve existing native ink/audio manifest fields rather than rolling back newer replay metadata.
- **Unified detailed design:** [手写、录音、Note Replay 与 iPad 统一设计](https://github.com/amogadget/Gamma/blob/v0.4.0/docs/design/handwriting-recording-ipad.md) covers the complete architecture, protocols, failure handling and roadmap, separating historical proposals from delivered behavior.

## Upgrade and use Replay

1. Back up the existing Gamma data volume. Upgrade the server/image and refresh browser tabs; use a matching iPad client.
2. Open the target PDF in the updated iPad's native workspace and let it sync. Existing ink without browser previews is automatically prepared; editable originals remain unchanged.
3. Refresh Web/Desktop. On an audio block, choose **Open Note Replay → Play**. A recording must already have timing events; no timestamp-free recording can be made synchronized retroactively.
4. Missing/invalid/over-budget previews are explicitly gated, with an optional audio-with-static-notes fallback.

## Important limits

- Phase 5A replays **final surviving ink**, not complete historical erased/undo/redo states. In-progress raster reveal is approximate at overlaps; text is not keystroke history.
- Web/Desktop do not become PKDrawing editors. Original PDFs are not automatically flattened with handwriting on export.
- Native recording pauses on leaving/background/interruption and requires explicit resume; continuous lock-screen/background capture and gapless rollover are not promised.
- WebKit touch/IME/provider/OAuth/file/clipboard behavior and long physical Pencil/microphone sessions still need device acceptance. Reusing Web UI does not port Electron's local server/process management onto iPad.
- Private ink/audio assets still require the owning account; a public share link does not grant access to them.
- Existing structural whole-tree save semantics are not a general realtime collaborative merge protocol.

## Validation

Pre-release checks include backend Ruff/full tests, frontend unit tests/ESLint/build, the complete native simulator suite, Desktop lint/unit tests and extension manifest/package validation. Native tests use real PencilKit and AVFAudio output; browser tests use an AAC-capable Chrome, not an unsupported Chromium build with a simulated audio clock. Real backend integration covers source preservation, preview backfill and recording timeline round-trip. See [validation evidence](https://github.com/amogadget/Gamma/blob/v0.4.0/ipad/VALIDATION.md) and [browser Replay details](https://github.com/amogadget/Gamma/blob/v0.4.0/docs/dev/note-replay.md).

## Abstract counterparts

Three of the slots also exist as abstract, animated SVG scenes — the idea of
the interaction drawn in the branding style rather than a recording:
`docs/assets/branding/gamma-demo-{annotate,notes,search}-light.svg` (light
only), generated by `tools/branding/build-demos.py`. They sit in the
[user guide](../../user_guide.md); the README keeps the recordings. The
trade-off is in [docs/research/demo-production.md](../../research/demo-production.md).
